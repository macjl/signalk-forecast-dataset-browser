# Forecast Dataset Browser roadmap

## Embed the Browser in Signal K

- [ ] Open the Browser inside the Signal K Admin UI so the navigation and toolbar stay available while browsing datasets.

## Import GRIB files into the onboard catalogue

- [ ] Import one GRIB file or several files from the same run. A crew can add a forecast received by email or Winlink, or copied from a USB drive, using the boat's local network.
- [ ] Publish the original files through the [Forecast Dataset Provider](https://github.com/macjl/signalk-forecast-dataset-provider) so they can be analysed by [GRIB Processor](https://github.com/macjl/signalk-grib-processor) and discovered by onboard apps alongside automatic downloads.
